재감염 SEIR 전파 시뮬레이터

감염병의 특성과 초기 발생 조건을 넣으면 실제 경계·인구·이동망 위에서 시간에 따른 확산을 계산하고 지도와 그래프로 보여 준다. 재감염(감염 횟수별 감수성·전파력·치명률), 면역 소실, 사망을 포함한다.

1. 새 시뮬레이션

감염병 매개변수, 초기 감염 위치·인원, 지역 간 이동, 방역 조건을 정하고 실행한다.

2. 결과·비교

지도 애니메이션, 지역별 통계, 그래프, 시나리오 비교, 내보내기.

3. 예측 검증

COVID-19 12개국 자료로 잰 과거 예측 성능 (지속 예측·ML·보정 SEIR 비교).

값의 종류 표시

표시뜻
실제 관측공식·공개 자료의 원값 (출처는 "자료 출처·갱신")
2차 자료원출처가 기록되지 않은 집계 (예: 대한민국 시도 인구)
추정값실제 자료로 추정한 값 (예: 3단계 u(t), 보고 지연)
사용자 입력이 화면에서 사용자가 넣은 값
기본 가정값근거 자료 없이 정한 기본값 (COVID 유사 코드 검증용, 항공 이동 규모 등)
시뮬레이션 결과가정에 따른 계산 결과 (예측 아님)
검증된 예측과거 자료로 성능을 잰 방법의 예측 (성능은 "예측 검증" 참고)
이 도구는 연구·시나리오 분석용이다. 실제 자료로 보정하지 않은 매개변수, 가정에 의존하는 이동망, 검증되지 않은 새 감염병의 결과는 미래를 예측한 값이 아니다.

최근 작업

현재 수치

대기
오른쪽에서 조건을 정하고 실행하면, 지도와 함께 시점별 수치가 여기서 바뀐다.

감염이 많은 지역 (10만 명당)

    값은 모형 안의 실제 감염 상태다 (관측 확진자 수가 아님). 시뮬레이션 결과

    지도를 눌러 발생 지역을 고른다. 색은 감염자 수(로그 간격)이며, 실행하면 시간에 따라 바뀐다.

    입력 시나리오 = 가정에 따른 결과

    입력 자료 (출처·시점·값의 종류)
    1. 기본
    2. 자료 시기 (지리·인구·기후)

    기본은 확보한 가장 최신 자료다. 다른 시기를 고르면 같은 이동 가정값으로 데이터셋을 다시 만든다. 확보하지 못한 시기는 목록에 없다.

    새 기후 기간 계산 (ERA5, 네트워크 사용)

    3. 감염병 특성
    고급 매개변수 (재감염·전파력·치명률 구조)

    R0 와 전파율 c0 의 관계는 모형 구조에 따라 다르다. 선택한 R0 기준(5절)으로 c0 를 정하고, 나머지 매개변수는 R0 로 정해지지 않으므로 따로 넣는다. 비워 둔 칸은 기본 가정값이다.

    4. 초기 발생 조건

    I = 감염 중(전파 가능), E = 잠복(아직 전파 안 함). "발생 지역 고르기" 모드에서 지도를 누르면 추가된다.

    5. 공간·환경

    기후 효과는 실제 자료로 추정하지 않았다. 켜면 사용자 가정값으로 표시된다.

    6. 방역·개입 u(t)

    접촉 감소 비율 0~1, 구간 [시작일, 끝일). 백신 구획은 방정식에 없다 (시작 시 면역 비율이나 u 로 근사하고 가정임을 기록한다).

    7. 매개변수 불확실성 (선택)

    범위를 켠 값은 실행마다 [하한, 상한] 에서 균등하게 한 번 뽑는다 (사용자 가정 범위). 결과 띠가 확률적 변동과 함께 이 불확실성을 반영한다. 끄면 띠는 확률적 변동만 반영한다.

    8. 계산 설정 (고급)

    ε 가 작을수록 정확하고 느리다. 기본 0.003 은 조건별 실험(docs/reports/D007_D004.md)에서 하이브리드가 시험 모형 모두에서 CTMC 와 일치한 값이다. 전 세계 데이터셋은 0.01 도 통과했다 (1회 약 1분).

    예측 검증 과거 자료로 잰 성능

    각 기점에서 그날까지의 자료만으로 만든 예측을 나중의 실제 관측과 비교한 결과다. 이 12개국·이 기간의 결과이며 다른 시기·병원체의 정확도를 보장하지 않는다. 자료는 나중에 정정된 최종판이라 실시간 성능보다 낙관적일 수 있다.

    국가별 과거 예측 보기

    최신 자료 예측 예측 (기점 이후 4주)

    WHO FluNet 실험실 검사 자료(국가 × 감시 체계)의 주간 양성률 예측이다. 양성률은 감염자 수가 아니다 (검사 체계에 따라 다름). 받은 자료의 마지막 주는 덜 보고되어 있어 그 전 주를 기점으로 한다.
    나라별 예측 양성률 (ML + 구간 보정 중앙값)

    한 나라에 감시 체계가 여럿이면 기점 주 검사 수가 가장 많은 계열을 칠한다. 회색 = 선택된 계열 없음.

    이 저장소가 받은 확진·사망 자료(JHU CSSE)는 2023-03-09 에 끝난다. 따라서 여기서 만드는 예측은 그 시점 기준이며 오늘의 예측이 아니다.

    데이터 관리 (버전·검증·활성화·되돌리기)

    인구표로 새 버전 만들기 (1급 행정구역 데이터셋)

    CSV 열: id,population,source[,tier,reference_date,note]. 출처(source)가 없는 행은 받지 않는다. 새 버전은 등록만 되고, 검증 결과와 바뀐 점을 확인한 뒤 직접 활성화한다. 문제가 있으면 이전 활성 버전으로 되돌린다.

    자료 출처·갱신

    실제 관측 자료, 2차 자료, 가정값을 구분한다. 받지 못한 자료는 미확보로 둔다. 갱신 확인은 새 파일을 임시 폴더에 받아 SHA-256 을 비교하며, 실패하면 기존 자료를 그대로 쓴다. 바뀐 원자료는 이전 판을 보관한 뒤 교체한다.

    세 가지 결과의 차이

    • 시나리오: 사용자가 정한 R0·개입·초기 감염으로 방정식을 푼 결과. "이렇게 가정하면 이렇게 된다" 이며 예측이 아니다.
    • 예측 검증: 과거 각 시점에서 그때까지의 자료만으로 만든 예측을 실제와 비교한 성능.
    • 최신 자료 예측: 가장 최근 자료 기점에서 다음 4주를 예측한 값. 인플루엔자는 WHO FluNet 최신판(주간 양성률), COVID-19 는 자료가 끝난 2023-03 시점 기준.

    지도와 그래프의 값

    • 시나리오 지도의 I, E 는 모형 안의 실제 감염 상태다. 관측 확진자 수가 아니다 (확진 = 보고율 × 발병 + 지연, 3단계 관측 모형).
    • "10만 명당" 은 지역 인구 대비, "절대 인원" 은 사람 수다. 인구가 큰 지역이 절대 인원에서 크게 보일 수 있다.
    • 값은 확률적 실행들의 평균이며, 그래프 띠는 실행 간 분포(5–95% 또는 25–75%)다. 이 띠는 확률적 변동만 반영하고 매개변수 불확실성은 포함하지 않는다. 매개변수의 영향은 값만 바꾼 시나리오를 만들어 비교 기능으로 본다.

    계산 방법

    • ODE: 결정론적 평균 궤적 (1회). CTMC: 정확한 확률 경로 (느림). tau-leaping, SDE: 근사. 하이브리드: 감염자가 적은 지역은 정확한 사건, 많은 지역은 tau-leaping.
    • R0 기준: reference (기준 밀도·g = 1·u = 0 의 단일 지역), 기준 지역, 원점 지역, 인구가중 평균, 지역망. 어느 기준이든 c0 하나를 모든 지역에 쓴다.

    한계

    • 방정식에 백신·변이·연령 구조·해외 유입 항이 없다.
    • 감염병 기본값은 COVID 유사 코드 검증용 가정이다. 새 감염병의 특성을 이름만으로 알 수 없으며, 사용자가 넣은 값의 근거를 메모로 남겨야 한다.
    • 항공 이동 규모, 통근 비율, 접촉 비율은 가정값이다. 대한민국 시도 인구는 2차 자료다.
    • 기후 효과는 추정하지 않았다. 기후 자료는 대한민국 시도의 2020~2022 월 평균(관측소 기반)만 있다.
    • 예측 성능은 12개국 2020-07 ~ 2023-01 과거 검증 결과다.
