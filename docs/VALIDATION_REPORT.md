# 종합 검증 보고 (9단계)

이 문서는 단계별 검증 결과를 한곳에 모은다. 숫자는 모두 실제 실행·테스트 결과이며 각 줄에 근거 파일을 적었다.
실제 자료 검증과 합성 자료 검증을 구분한다. **합성 자료 결과는 코드·추정기의 정확성 점검이지 실제 예측 성능이 아니다.**

## 2. 실제 감염병 자료 (2단계)

근거: `docs/reports/2_data_quality.md`

- 품질 점검: 음수(소급 정정), 0 비율, 주 단위 보고, 요일 비, 급증, 출처 간 비교 (JHU 대 Google 누적 차이, 지연).
- 발견: OWID 현재 파일의 일별 확진은 주간 보고 형식이다 → 일별 분석은 JHU. 대한민국 시도 확진은 2020-09-09 까지뿐이고 2차 자료다.

## 3. 관측 모형·추정 (3단계)

근거: `docs/reports/3_calibration.md`, `tests/test_inference.py`

| 점검 | 자료 | 결과 |
|---|---|---|
| 추정용 적분기 = 엔진 ODE | 합성 4지역 | 최종 상태 상대 오차 < 1e-6 |
| 추정기 되찾기 (반복 20회) | **합성** | u(t) 95% 구간 포함률 0.97, 대부분 묶음 0.93~1.00, 확진 과산포만 0.85 |
| 12개국 적합 (2020-02 ~ 2021-10) | 실제 | 모두 수렴·헤시안 양의 정부호, 확진 90% 포함률(표본 안) 0.89~0.96 |
| 보고율 식별 | 실제 (대한민국) | 식별 안 됨 (목적함수 차이 0.09) → 가정값 |
| u(t) 해석 | 실제 | 12개국 모두 R_t 와 정책 강도 음의 상관 (−0.15 ~ −0.74) |
| 미래 자료 차단 | 합성 | fit_end 뒤 관측을 바꿔도 목적함수 동일 (테스트) |

약점: 확진 잔차 자기상관 (대한민국 0.52), 스웨덴 확진 PIT KS 0.22 (주 몇 회 보고 구조).

## 7. 공간 자료·업데이트 관리·통합 (6~7단계)

근거: `tests/test_data_versions.py`, `tests/test_integration.py`, `docs/reports/7_integration.md`
- 데이터셋 저장소: 등록 시 검증(인구·면적·접촉 행렬 행 합·이동 균형·기후 범위), SHA-256 확인, 활성화·되돌리기·버전 비교. 검증 실패 버전은 활성화 거부, 파일이 바뀌면 불러오기 거부 (테스트).
- 대한민국 시도 데이터셋 v1: 17개 시도, 인구 합 51,673,394 (2차 자료), 검증 통과.
- 추정 결과 → 엔진 설정: 엔진 ODE 가 대한민국 적합 궤적을 최종 상태 오차/인구 5.9e-9 로 재현.

## 8. 웹 애플리케이션 (8단계)

근거: `tests/test_web.py`, `tests/ui/smoke.mjs`
- API: 시나리오 실행·진행률·취소·결과·내보내기, 입력 검증(범위·형식·알 수 없는 항목·없는 지역), 경로 공격 차단, 데이터셋 활성화·되돌리기, 출처 없는 인구표 거부.
- 보안 (로컬 전용): 기본 127.0.0.1, Host 헤더 허용 목록(DNS 리바인딩 방지), 상태 변경 요청에 사용자 지정 헤더 요구(CSRF 방지), CORS 미허용, 작업 시간 상한, 지도 툴팁 HTML 이스케이프.
- 화면 시험 (Playwright, Chromium): 시나리오 실행 → 지도 다각형 17개·지역 표·시간 막대·그래프 툴팁, 시나리오 비교, 서버 입력 오류 표시, 모든 탭, 밝은·어두운 모드, 휴대폰 폭(390px) 가로 넘침 없음, 콘솔 오류 없음.
