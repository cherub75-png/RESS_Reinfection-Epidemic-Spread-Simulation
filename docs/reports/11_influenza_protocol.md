# 11. 인플루엔자 시간순 예측 검증 규약 (실행 전에 정함)

이 문서는 인플루엔자 예측 결과를 보기 전에 작성했다 (git 기록으로 시점 확인 가능). 결과를 본 뒤 바꾼 항목은 아래 "변경 기록" 에 남긴다.
COVID-19 규약(`5_protocol.md`)과 같은 원칙을 따른다: 기점까지의 자료만 쓰고, 무작위 분할을 쓰지 않으며, 하이퍼파라미터를 시험 결과로 조정하지 않는다.

## 1. 자료와 통합 규칙 (WHO FluNet, `data_raw/who_flunet/VIW_FNT.csv`)

자료를 보기만 하고(예측 결과는 보지 않고) 확인한 사실 (2026-11-09 받은 판):
- 190,462행, ISO 주 시작일 1995-01-02 ~ 2026-11-02. 감시 체계 `ORIGIN_SOURCE`: NOTDEFINED 87,013 / SENTINEL 59,808 / NONSENTINEL 43,641 행.
- 모든 열이 같은 완전 중복 행이 84쌍 있다.
- `INF_ALL` = `INF_A` + `INF_B` (모든 행).
- `SPEC_PROCESSED_NB` (처리 검체 수) 결측 6.9%. 양성 수보다 작은 행 1,089개 (예: 스위스 NONSENTINEL 은 검체 합 11, 양성 합 166,112): 검체 수를 보고하지 않은 것으로 본다.
- 영국은 잉글랜드(X09)·웨일스(X10)·북아일랜드(X11)·스코틀랜드(X12) 로 나뉜다.
- 대한민국: NOTDEFINED 2001-08 ~ 2021-09, SENTINEL 2020-08 ~ 현재. 감시 체계가 바뀌어 계열이 끊긴다.
- 최근 주는 덜 보고되어 있다 (나중에 채워짐). 마지막 주 2026-10-26: 평소(직전 8주 중앙값) 대비 검체 수 중앙값 0.50, 40% 가 비어 있음. 그 전 주 0.96 (19% 빔), 3주 전부터 1.0 안팎.
- 코로나19 시기에 인플루엔자가 거의 사라졌다: 북반구 2020/21 절기 양성률 0.4% (2015~2019 절기 15.5~20.7%).

통합 규칙
- R1. 완전 중복 행은 하나만 남긴다.
- R2. 계열 = (국가 코드, 감시 체계). SENTINEL·NONSENTINEL·NOTDEFINED 를 합치거나 잇지 않는다 (검체를 모으는 집단이 다름). 대한민국의 두 계열도 잇지 않는다.
- R3. 검사 수 n = `SPEC_PROCESSED_NB` (결측이 아니고, 0 보다 크고, `INF_ALL` 이상일 때). 아니면 n 결측 → 그 주 양성률 없음.
  양성 수 x = `INF_ALL`. n 이 있고 `INF_ALL` 이 비어 있으면, `INF_NEGATIVE` = n 일 때만 x = 0, 아니면 결측.
- R4. 양성률 p = x / n. 특성(입력)으로는 n ≥ 10 인 주만, 예측 대상(정답)으로는 n ≥ 20 인 주만 쓴다.
- R5. 주는 ISO 주 (월요일 시작). 영국 4개 계열의 기후 특성은 영국(GBR) 전체 값을 쓴다 (경계 자료에 4개 지역이 따로 없음; 근사).
- R6. 자료는 받은 날의 최종판이다. 과거 시점에 실제로 보였던 판(빈티지)이 없어 소급 보완 효과를 재현할 수 없다 → 검증 결과는 실시간 성능보다 낙관적일 수 있다. 오늘부터 받은 판을 보관한다 (`seir_sim/data/updater.py`).

## 2. 계열 선택 (시험 기간 자료를 보지 않는 규칙)
- 학습 기간 2017-09-25 ~ 2022-09-19 에 (R3 의) 검사 수가 있는 주가 80% 이상이고, 그 기간 주간 검사 수 중앙값이 50 이상인 계열.
- 선택 결과(계열 목록)는 실행 기록에 남긴다. 시험 기간에 자료가 없는 주는 평가에서 빠질 뿐 다른 계열로 바꾸지 않는다.

## 3. 예측 대상과 기점
- 기점 o: 2022-10-03 부터 2026-09-21 까지 매주 (월요일). 기점의 "마지막 관측 주" = o 로 시작하는 ISO 주.
- 대상: o + 1 ~ 4 주 각 주의 양성률 (n ≥ 20 인 주만 정답으로 쓴다). 예측 분포 = 9개 분위수 (0.025, 0.05, 0.1, 0.25, 0.5, 0.75, 0.9, 0.95, 0.975).
- 시기 구분 (보조): 대상 주의 반구와 위도: 북반구 온대 (위도 ≥ 23.5° N), 남반구 온대 (≥ 23.5° S), 열대 (|위도| < 23.5°). 위도는 국가 경계의 면적 가중 중심.

## 4. 방법 (모두 기점까지의 자료만 씀)
| 이름 | 내용 |
|---|---|
| persistence | 마지막 관측 양성률. 분위수 = 그 계열의 과거 같은 방법 오차 (logit 척도) 의 대칭 경험 분위수 (COVID 와 같은 방식, 오차 8개 미만이면 없음) |
| trend | logit 양성률의 마지막 1주 변화를 감쇠(φ = 0.75) 해 연장. 분위수 = 과거 오차 경험 분위수 |
| seasonal | 같은 ISO 주 ±1 주의 과거 절기 양성률 (기점 전 자료, 최근 8개 절기까지, 2020-03-01 ~ 2022-06-30 제외) 의 중앙값. 분위수 = 그 값들의 경험 분위수 (값 5개 미만이면 없음) |
| ml | 계열 공통 분위수 GBM (국가 식별자 없음). 하이퍼파라미터는 COVID 와 같다 (`seir_sim/ml/quantile.py` ML_PARAMS) |
| ml_cal | ml 분위수 + 시간순 구간 보정 (6절) |
| ml_noclim | 기후 특성을 뺀 ml (기후 자료의 예측 기여 시험) |
| ml_loco_KOR | 대한민국 계열을 빼고 학습한 ml 의 대한민국 예측 (특정 국가 과적합 시험) |
| seir (보조) | 1절 방정식의 단일 지역 모형 + 양성률 관측 모형 (7절). 정해진 일부 계열, 4주 간격 기점 |

ML 학습·특성
- 학습 행: 선택된 계열의 (주 s, 예측 주 h), s ≥ 2010-01-04, 대상 주 s + h 가 기점 o 이하이고 정답(n ≥ 20) 이 있는 것. 모형은 첫 기점과 그 뒤 4주마다 다시 학습하고, 다음 재학습 전 기점들에 쓴다.
- 대상: 대상 주의 logit((x + 0.5) / (n + 1)). 예측 분위수를 양성률로 되돌리고 행마다 정렬한다.
- 특성 (모두 주 s 까지의 자료로 계산): logit 양성률 z_s, z_{s-1}, z_{s-2}, z_{s-3}; 변화 z_s − z_{s-1}, z_s − z_{s-2};
  log(1 + n_s), log(1 + n_s) − 직전 4주 평균; ISO 주의 sin·cos; 북반구 여부; |위도|; 예측 주 h;
  대상 주 ISO 주의 과거 절기 평균 logit 양성률 (seasonal 과 같은 규칙); 대상 주 52주 전의 logit 양성률.
- 기후 특성 (ERA5, 국가 단위 주 평균; 매일 00·12 UTC 표본): 주 s 의 기온·절대습도, 직전 4주 평균 절대습도, 대상 주 ISO 주의 과거 연도 평균 절대습도(기점 전 연도만), 주 s 의 절대습도 편차 (같은 ISO 주 과거 평균과의 차).
  대상 주의 실제 날씨는 쓰지 않는다 (기점에서는 모르는 미래 자료).
  절대습도 AH [g/m³] = 2166.8 · e / (T + 273.15), e = e_s(이슬점) [kPa] (Tetens). 2026-07 이후는 ERA5T 예비판이다 (표시함).

## 5. 지표
- 1차 지표: 자연 척도 WIS (양성률, %p) 의 평균을 persistence 와 비교한 비 (상대 WIS). 같은 행 집합(비교하는 모든 방법의 예측과 정답이 있는 행)에서만 비교. 예측 주별, 계열 모두 모아서.
- 2차: 50/80/90/95% 구간 포함률, 중앙값 MAE, 지역 묶음(3절)별 상대 WIS, LOCO, 기후 특성 기여 (ml / ml_noclim), seir 보조 비교 (그 계열·기점의 같은 행에서).
- 해석: 상대 WIS < 1 이면 persistence 보다 낫다. 0.95 ~ 1.05 는 "비슷". 통계 검정은 하지 않는다 (기점 간 자기상관).

## 6. 예측 구간 보정 (ml_cal; COVID 5단계에서 ML 구간이 좁았던 문제의 해결 시도)
- 기점 o, 예측 주 h 의 보정 표본: 같은 방법의 과거 표본 밖 예측 중 대상 주 ≤ o (정답이 이미 알려짐) 이고 기점이 [o − 52주, o) 인 것, 모든 계열을 모아서.
- 보정 표본이 300행 미만이면 보정하지 않는다 (기록).
- 변환 척도 z (인플루엔자: logit 양성률, COVID: log(1 + 주간 수)) 에서 분위수 수준 τ_k 마다 δ_k = (z_정답 − q_k) 의 τ_k 경험 분위수, q'_k = q_k + δ_k, 행마다 정렬.
- 성공 판정 (미리 정함): 90% 포함률이 0.85 ~ 0.95 이고, 보정 후 WIS 가 보정 전의 1.05 배 이하.
- 같은 규칙을 COVID 5단계 결과(`outputs/stage5/forecasts_k14.parquet` 의 ml, hybrid, seir)에 그대로 적용해 다시 평가한다 (재적합 없이, 기점 전 정답만 씀).

## 7. seir 보조 비교 (정해진 계열, 4주 간격 기점)
- 계열: KOR SENTINEL, USA SENTINEL, NOR NONSENTINEL, ESP SENTINEL, JPN SENTINEL, SGP SENTINEL, AUS NOTDEFINED, CHL NONSENTINEL, BRA NONSENTINEL, ZAF SENTINEL 중 2절 선택을 통과한 것 (통과 못 하면 빼고 바꾸지 않음).
- 기점: 2022-10-03 부터 4주마다 (위 기점의 부분 집합).
- 모형: 1절 방정식, 단일 지역 (인구 = World Bank 해당 국가 최신 연도). 감염병 값은 인플루엔자 **가정값**: 잠복(E) 1.5일, 감염(I) 4일, 면역 소실 1/365 일⁻¹, 치명률 0 (사망 관측을 쓰지 않음), 재감염 구조 P·T·M 은 1단계 기본값. R0_max = 4.
- 창: 기점 주 끝에서 182일 전부터. 추정: u(t) 14일 구간 (z 무작위 걷기 sd 0.5), 창 시작의 I0 (log 정규 사전 N(log(1e-5 N), 3²)), 창 시작 감수성 비율 s0 (logit 정규 N(logit 0.6, 1²); 나머지는 보호 상태 R^P_1), 관측 척도 c (log 정규 N(log 1e-3, 2²)), 과산포 κ (log 정규 N(log 100, 1.5²)).
- 관측: 주간 양성 수 x_w ~ BetaBinomial(n_w, 평균 p_w, 농도 κ), p_w = inc_w / (inc_w + c), inc_w = 그 주의 발병(E → I) / N.
  (양성률 = 인플루엔자 환자 / (인플루엔자 환자 + 다른 원인 호흡기 환자) 로 보고, 다른 원인 비율을 c 로 둔 근사)
- 예측: 마지막 구간 u 유지 + 라플라스 근사 표본 300개 (COVID 와 같은 방식). 이 모형은 감염 규모의 절대값을 잘 식별하지 못한다 (c 와 감염 규모가 함께 움직임) — 결과 해석에 적는다.

## 8. 최신 자료 예측 (운영)
- 받은 판의 마지막 주는 덜 보고되어 있으므로(1절), 기점 = 받은 판에서 두 번째로 최근 주. 계열의 기점 주 검사 수가 직전 8주 중앙값의 50% 미만이면 "기점 주 미완성 가능" 경고.
- 방법: persistence, seasonal, ml_cal (+ 해당 계열이면 seir). 모든 출력에 자료 마지막 주, 받은 날, 검증 성능 요약을 함께 표시한다.
- 1주 뒤 대상은 이미 일부 보고가 시작된 주일 수 있다 (사실상 현재 추정).
