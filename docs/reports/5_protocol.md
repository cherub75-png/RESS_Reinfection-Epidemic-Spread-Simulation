# 5단계 시간순 예측 검증 규약 (실행 전에 정함)

이 문서는 예측 결과를 보기 전에 작성했다 (git 기록으로 시점 확인 가능). 결과를 본 뒤 바꾼 항목은 아래 "변경 기록" 에 남긴다.

## 대상
- 자료: JHU CSSE 국가별 누적 확진·사망의 일별 차분 (최종판). 12개국: KOR JPN NZL AUS GBR DEU ITA USA BRA IND ZAF SWE
- 예측 대상: 기점 다음 주부터 1~4주 각각의 주간 합 (월~일). 예측 길이 7·14·21·28일.
- 주 안에 결측일이 있거나 주 합이 음수인 주는 대상과 이력에서 뺀다.
- 기점: 2020-07-05 부터 2022-12-25 까지 2주마다 (일요일). 기점 t 의 예측은 t 일까지의 자료만 쓴다.

## 방법
| 이름 | 내용 |
|---|---|
| persistence | 마지막 주 값. 분위수 = 과거 같은 방법 로그 오차의 대칭 경험 분위수 |
| trend | 마지막 1주 로그 변화를 감쇠(phi = 0.75)해 연장. 분위수 = 과거 로그 오차 경험 분위수 |
| seasonal52 | 52주 전 값. 52주 이력이 있는 기점에서만 (부분 집합 비교) |
| seir | 보정 SEIR (1절 방정식, 단일 국가), 기점마다 순차 재추정 (창 182일), 4주 예측 분포 |
| ml | 국가 공통 분위수 GBM (국가 식별자 없음). 학습 = 모든 국가의 (s, h) 중 s + 7h <= t |
| hybrid | SEIR 중앙값 x exp(ML 잔차 분위수). 잔차 학습 = 이전 기점 SEIR 예측 중 대상이 t 까지 관측된 것 |

하이퍼파라미터는 코드에 고정했고 시험 기간 결과로 조정하지 않는다 (`seir_sim/ml/quantile.py`, `seir_sim/forecast/seir.py`).

## 지표
- 1차 지표: 로그 척도 WIS (log(1 + y), 9개 분위수) 의 평균을 지속 예측과 비교한 비 (상대 로그 WIS). 같은 행 집합에서만 비교.
- 2차 지표: 자연 척도 WIS 의 국가별 비의 기하평균, MAE, RMSE, MASE, 50/80/90/95% 구간 포함률, 90% 구간 로그 폭, 로그 편향, SEIR 표본 CRPS.
- 정점: 주간 log(1 + y) 의 지역 최대 중 양쪽 돌출 log 2 이상, 주 50건 이상. 관측 정점이 예측 1~4주 안에 든 기점에서 중앙값 경로의 정점 주 오차와 크기 로그 비.
- 시기: 대상 주 끝날 기준 pre-Delta (~2021-06), Delta(근사, 2021-07~11), Omicron(근사, 2021-12~). 국가별 변이 우세 시점 자료는 확보하지 않았으므로 달력 근사다.

## 해석 규칙
- 상대 로그 WIS < 1 이면 지속 예측보다 낫다고 쓴다. 차이가 작으면 (0.95~1.05) "비슷" 으로 쓴다. 통계 검정은 하지 않는다 (기점 간 자기상관이 커서 독립 표본 검정이 맞지 않음).
- 무작위 분할 결과는 쓰지 않는다. 모든 비교는 시간순이다.
- 이 검증은 과거 자료 검증이며 다른 병원체·국가·시기의 정확도를 보장하지 않는다.

## 부가 실험
- SEIR 구간 길이 7일 대 14일: 계산량 때문에 일부 국가에서 비교한다 (국가 목록은 실행 기록에 남김).

## 변경 기록
- 결과를 보기 전에 부가 비교 하나를 더했다: 국가 제외 학습 ML (대한민국 자료 없이 학습한 모형으로 대한민국 예측). 1차 지표·방법·기점은 바꾸지 않았다.
- SEIR 순차 재추정의 계산 속도를 높이려고 고정된 앞 구간의 적분 결과를 재사용했다 (결과는 처음부터 적분한 것과 같음: 테스트). 결과를 보기 전의 변경이다.
- 비교 대상 중 "보정하지 않은 기존 ODE" 와 "CTMC·하이브리드 엔진 예측" 은 제외했다. 이유: (1) 보정하지 않은 ODE 는 관측 자료를 쓰지 않아 기점별 예측을 만들 수 없다 (같은 ODE 를 보정한 것이 '보정 SEIR'). (2) 국가 단위 인구(수백만~수억)에서 확률적 엔진의 과정 잡음은 관측 잡음·매개변수 불확실성보다 훨씬 작다 (7단계: 대한민국 하이브리드 30회 평균과 ODE 의 상대 차이 중앙값 0.05, 주로 초기 시점 차이). 계산량 대비 얻는 정보가 적어 제외했다.
