# 1단계 최종 보고 (시뮬레이션 엔진)

작성: 자율 진행 종료 시점. 브랜치 `claude/global-reinfection-seir-cubnxv`.

## 1. 요약
- 지시서 1단계 1~6항을 모두 구현했다.
  - 기술 스택, 데이터 계층, 모형 계층(ODE, SDE, CTMC, tau-leap, 하이브리드), 앙상블 실행기, 테스트, 명령줄과 예제 그림
- 전체 테스트 **156개 통과** (`python -m pytest`, 약 5분, 4코어 클라우드 환경).
- **실제 자료로 만든 지역은 전 세계 국가 단위(246개)뿐이다.** 대한민국 시도 17개는 경계만 실제 자료이다. 인구 격자 서버가 이 환경의 네트워크 정책으로 차단되어 인구가 미확보 상태이고, 그래서 시나리오가 실행되지 않는다 (값을 지어내지 않음).
- 감염병 매개변수는 모두 **코드 검증용 가정**이다. 아래 결과는 **예측이 아니다.** 실제 자료 보정은 2단계 일이다.

## 5. 사용자 확인이 필요한 결정 (`docs/DECISIONS.md`)
1. **D-004**: SDE 음수 처리 기본값을 `flow_limit` 으로 바꿨다. 승인안 `increment_clip` 은 dt → 0 에서 편향이 발산함을 확인했다.
2. **D-008**: 전 세계 규모에서 network R0 기준은 바티칸 같은 극단 지역이 정한다. 기준을 다음 중에서 정해 주세요.
   - (a) reference
   - (b) 인구가중 평균
   - (c) 원점 지역
3. **D-007**: 최종 규모처럼 정밀한 지표에는 eps = 0.003 을 권고한다 (기본 0.01 유지).
4. 가정 매개변수 값: 항공 이동 규모, 통근 비율, 목적지 접촉 비율 (전 세계 / 대한민국 예제 값). 2단계에서 자료로 대체하거나 추정할 대상이다.

## 6. 알려진 한계와 미완성
- 성능: 전 세계 하이브리드 1회 약 2분. 이항 leap 의 이동 배분 난수 비용이 주원인이다.
  - 후보: 이동만 긴 단계로 분리 (검증 필요)
  - 후보: 정확 사건의 감염력 증분 갱신
- 국가 평균 밀도는 접촉 밀도의 대리값으로 약하다. 인구 격자를 확보하면 인구가중 밀도를 권고한다 (입력만 바뀜, D-008).
- 국가 단위 통근 C 는 대표 좌표 사이 radiation 모형이라 거칠다. 국경 통근 자료로 대체가 필요하다.
- 기후 g: 코드와 합성 검증만 있다. 기후평년값은 2단계 과거 재현에 부족하므로 ERA5 같은 일별 자료가 필요하다.
- 2단계 이후 모듈(`inference`, `ml`, `forecast`)은 미구현이다 (지시대로 1단계에서 멈춤).

## 7. 2단계 준비 사항 (사용자 입력 필요)
- 실제 감염 자료: 질병명, 지역, 기간, 파일 또는 출처, 예측 목표(확진·입원·사망), 정확도 지표 선호
- 네트워크 허용 또는 파일 제공 (위 4절)
- 위 5절의 결정
- 권장 노력 수준: **엑스트라(xhigh)**. 관측 모형·우도·입자 필터 설계와 시간 분리 검증에서 실수 비용이 크다.
