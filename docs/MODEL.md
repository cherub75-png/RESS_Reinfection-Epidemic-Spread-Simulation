# 수학 모형 노트 (1-A)

작업 지시서 1절의 방정식을 기준으로 한다. 이 문서는 구현할 때 확인한 해석, 색인 규약, 유도를 기록한다.
방정식의 의미는 바꾸지 않았다.

## 1. 색인 규약

| 기호 | 뜻 | 쓰는 구획 |
|---|---|---|
| P(n) | **n번째 감염**에 대한 감수성 | S 는 P(1) = P_1, R_l 은 P(l+1) |
| T(n) | n번째 감염 중인 사람의 전파력 | I_n |
| f(n) | n번째 감염의 치사율 | I_n |
| m(l) = min(l+1, M) | R_l 이 재감염될 때 들어가는 E 칸 | |

일관성 확인: S 는 감염 이력이 없다. 따라서 S 가 쓰는 P_1 은 P(1) 과 같고, "첫 감염 감수성" 이라는 해석과 맞는다.

## 2. P(n, τ) 와 P(n+1, τ): 표기 차이인가, 정의 차이인가

1.2절의 P(n, τ) = P(n) + [P_1 − P(n)](1 − e^{−λτ}) 에서 n 은 "다음에 일어날 감염의 번호" 이다.
l회 감염 후 회복한 사람(R_l)이 다음에 걸리는 감염은 (l+1)번째다. 따라서 그 사람의 감수성은 P(l+1, τ) 이다.
지시서의 "기댓값이 정확히 P(n+1, τ)" 에서 n 은 구획 R_n 의 감염 횟수다. 두 표기는 같은 대상을 가리킨다.
P 는 다음 감염 번호로, R 은 지난 감염 횟수로 색인한 것뿐이므로 **표기(색인 기준) 차이이며 정의 차이가 아니다.**

**기댓값 일치 (정확).** 재감염이 없을 때(Λ = 0), 회복 시점부터 τ 가 지나도 R^P 에 남아 있을 확률은 e^{−λτ} 이다. 따라서

  E[감수성] = e^{−λτ} P(l+1) + (1 − e^{−λτ}) P_1 = P(l+1, τ).

`tests/test_waning_index.py` 는 사건 목록에서 만든 선형 동역학의 행렬지수로 이 식이 정확히 성립함을 확인한다 (M = 1, 3, 4).

**주의: 위험률 모형과는 Λ 의 2차에서 다르다.** Λ > 0 이면 2상태 마르코프 모형 (R^P: 위험률 ΛP(l+1), R^W: 위험률 ΛP_1) 의 생존확률은

  E[exp(−∫ h(X_s) ds)] ≥ exp(−∫ E[h(X_s)] ds) = exp(−∫ Λ P(l+1, s) ds)   (Jensen 부등식)

을 만족한다. 등호는 P(l+1) = P_1 일 때만 성립한다. 즉 모든 사람에게 결정론적 감수성 P(l+1, τ) 를 주는 "회복 경과시간 τ 구조 PDE" 모형과 비교하면, 마르코프 구현은 재감염을 조금 덜 만든다.
- 차이는 Λ 의 1차에서는 0 이고 2차에서 나타난다. 테스트에서 Λ 를 절반으로 줄이면 차이가 약 1/4 로 줄었다.
- 크기 예시 (τ = 120일, P(2) = 0.5747): Λ = 0.002/일이면 생존확률 차이 2.1×10⁻⁴, Λ = 0.02/일이면 3.5×10⁻³ (상대 2.4%).
- 1.5절은 "ODE 의 각 항이 하나의 사건" 인 CTMC 를 기준으로 정했다. 그러므로 **기준 모형은 마르코프(2상태) 해석이다.** 위험률(PDE) 해석이 필요하면 별도 승인을 받아 다룬다.

## 3. 마지막 칸 R^P_M 의 감수성 P(M+1)

M 칸은 "M회 이상" 을 뜻한다. E_M 은 R_{M−1}(M번째 감염)과 R_M(M+1번째 이상 감염)에서 모두 들어온다.
절단 모형은 다음 "고정(freeze)" 함수를 쓴 무한 칸 모형과 **정확히 같다.**

  T̃(k) = T(min(k, M)),   f̃(k) = f(min(k, M)),   P̃(k) = P(min(k, M+1)).

- I_M 은 T(M), f(M) 을 쓴다. 이는 T̃, f̃ 와 일치한다.
- R^P_M 은 P(M+1) 을 쓴다. 이는 P̃ 와 일치한다. R^P_M 에는 정확히 M회 감염된 사람이 포함되므로 그 사람들에게는 정의 그대로의 값이기도 하다.
- 대안인 P(M) 은 (M−1)회 감염자의 감수성이다. 그러면 R_{M−1} 과 R_M 의 감수성이 같아져 고정 규약과 어긋나므로 쓰지 않는다.

절단 오차 (k > M 인 사람에게만 생긴다)
- 감수성: |P(M+1) − P(k+1)| ≤ (P_1 − P_min) e^{−αM}. 지수적으로 작아진다.
- 전파력: 0 ≤ T(M) − T(k) < T_1 M^{−β}. β = 0.3 이면 천천히 작아진다 (M = 4 에서 0.66 T_1 미만).
- 치사율: |f(M) − f(k)| < f_1 φ(M).
- 따라서 M 에 대한 수렴은 주로 "M회를 넘게 감염되는 사람의 비율" 이 얼마나 작은지에 달려 있다.
M 을 키울 때 결과가 수렴하는지는 1-B 에서 ODE 로 측정한다.
**결론: 1.4절 방정식 그대로(P(M+1)) 사용하며, 따로 칸을 통합하는 방식은 필요하지 않다.**

**1-B 측정 결과 (docs/reports/1B_ode_validation.md 4절)**
- 동치 검증: M0 칸 모형과 "M0 이후 고정한 함수를 쓰는 M1 칸 모형" 의 결과가 적분 오차 수준(1.8e-8)까지 일치했다. 일부러 틀린 대조군은 차이가 O(1) 이었다.
- 수렴 (단일 지역, R0 = 2.5, λ = 1/180, 기준 M = 20)

  | M | 365일 I / D 오차 | 3년 I / D 오차 |
  |---|---|---|
  | 4 | 2.7% / 2.6% | 6.2% / 23% |
  | 8 | 1.4e-5 / 6.4e-6 | 2.1e-3 / 2.8e-3 |

  10년이 되면 M = 16 도 1e-4 수준이다.
- 원인은 면역 소실이 빨라(평균 180일) 1년 안에 여러 번 재감염되는 것이다. 마지막 칸(M회 이상)으로 감염이 몰리고, 고정된 T(M), f(M) 이 실제 T(k), f(k) 보다 크다.
- 진단: 적분 결과 `meta["last_bin_share"]` 에 마지막 칸 점유율을 기록한다. I_M / I_total 이 0.01 이하이면 오차가 1e-4 이하였다.

## 4. R_0, c_0, 초기 증가율

다음 세대 행렬: 감염 구획 (E_{n,i}, I_{n,i}) 에서 dx/dt = (F − V)x 로 두면

  F[E_{n,i}, I_{k,j}] = A_{n,i} g_i c_i C_ij T(k) / N_j,
  A_{n,i} = 1{n=1} P_1 S_i + Σ_{l: m(l)=n} (P(l+1) R^P_{l,i} + P_1 R^W_{l,i}),

이다. V 는 σ, γ, 이동(ω) 항을 담는다. R = ρ(F V⁻¹) 이다.

- 단일 지역, 전원 감수성, 이동 없음: R_0 = g c_0 h (1−u) P_1 T_1 / γ = κ/γ. (사망도 I 이탈 γ 에 포함되므로 분모는 γ 이다.)
- 이동이 없고 g c_i 가 지역마다 같으며 C 의 행 합이 1이면, F 는 κ diag(N) C diag(1/N) 과 닮음 행렬이다. 따라서 R_0 = κ/γ 로 같다 (테스트로 확인).
- 일반적으로 R 은 c_0 에 선형이다. 그래서 c_0 = R_0 / R(c_0 = 1) 이 정확하다. h, g, u, C, ω, 인구 분포의 영향이 모두 R(c_0 = 1) 에 들어가므로 "R_0 ∝ c_0 P_1 T_1 / γ" 같은 단순 관계를 가정하지 않는다.
- 설정 `transmission.r0_reference` 로 기준을 고른다.
  - `reference`: 기준 조건 R_0 = c_0 P_1 T_1 / γ
  - `network`: t_0 시점 실제 지역망의 스펙트럼 반지름
  - 실행 기록(`derived`)에는 두 값을 모두 남긴다.
- 초기 증가율: E_1, I_1 선형화 → r = [−(σ+γ) + √((σ−γ)² + 4σκ)]/2. 테스트는 사건 목록 drift 의 수치 야코비안 고유값과 비교한다.

### 4.1 이동 불균형과 R0 (1-B 에서 발견)

무감염 상태가 정지 상태가 되려면 각 지역의 순이동이 0 이어야 한다. 즉 Σ_j ω_ji N_j = Σ_j ω_ij N_i 이다.
불균형 ω 에서는 감염이 없어도 이동만으로 인구가 재분포된다 (1-A 의 무작위 합성 자료에서 한 지역 인구가 17배가 되었다). 그러면
- t0 인구로 계산한 R0_network_t0 는 그 순간의 값일 뿐이다.
- 장기 성장률은 정지 인구 분포의 (F − V) 고유값을 따른다. 테스트로 상대 2e-3 이내 일치를 확인했다.

대응
- 합성 자료는 균형 이동(ω_ij N_i = ω_ji N_j)으로 생성한다.
- `r0_report` 에 `mobility_imbalance_per_day` 와 `R0_network_stationary` 를 기록한다.
- 실제 이동 자료(1-D)의 균형 여부는 전처리에서 측정해 보고한다.
- 방정식은 바꾸지 않았다.

### 4.2 R0 기준 선택 (기본 network)

`r0_report` 는 c0 를 어느 기준으로 정했든 다음 값을 모두 기록한다.
- R0_reference
- R0_network_t0
- R0_network_stationary
- 지역별 고립 R0 (R0_isolated_by_region)

실제 유행(예: 중국 발생 후 전 세계 확산)과 비교할 때는 원점 지역의 고립 R0, 지역망 R0, 관측 성장률을 함께 비교해 기준을 정한다 (2단계).
합성 17지역 예시에서는 두 기준의 R0 가 6% 달랐고 최고점 시점이 12일 차이 났다 (보고서 2절).

식별 가능성 메모 (2단계): 초기 증가와 R_0 에는 c_0 P_1 T_1 의 곱만 나타난다. 재감염 단계에서야 P(n) 과 T(n) 의 형태(α, β, P_min)가 따로 드러난다.

## 5. 시간가변 입력

ODE 적분기는 변화 시점마다 적분을 끊는다. 구간 안에서는 구간 시작 시점의 g, u 를 쓴다 (경계 불연속 오차 없음, u = 1 구간에서 S 가 정확히 상수임을 테스트로 확인).

g_i(t), u_i(t) 는 구간별 상수다. `Drivers.next_change(t)` 가 다음 변화 시점을 준다. CTMC 는 그 시점마다 다시 시작하므로 구간 안에서는 정확하다 (1-C).
환경 시계열은 일 단위 구간 [d, d+1) 에 적용한다.

g 의 기본 상태는 `status: neutral_default` (g = 1) 이다. "환경 효과가 없다" 는 추정 결과가 아니라 추정 전의 효과 없음 가정이다. 계수는 실제 자료로 추정하기 전에는 지정하지 않는다.

## 6. 정확한 CTMC (1-C)

`seir_sim/simulate/ctmc.py` 는 Gillespie direct method 로 구현했고, 공통 사건 목록을 그대로 쓴다 (numba 커널 = Python 식, 테스트로 확인).
- 구간 경계에서는 다음 사건 시각을 버리고 새 율로 다시 뽑는다. 지수분포의 무기억성 때문에 정확하다.
- 난수: SeedSequence -> PCG64 에서 균등난수를 묶음으로 받는다. 같은 시드면 같은 경로가 나온다. 시드는 meta 에 기록한다.
- 검증 (`docs/reports/1C_ctmc.md`)
  - 선형계의 정확한 평균·분산 (모멘트 방정식)
  - 초기 단계 평균 = ODE
  - 소멸 확률 = (1/R0)^k
  - 대유행 조건부 최종 규모의 평균·분산 (Andersson & Britton 2000)
  - 대수의 법칙: 단일 경로 편차가 1/√N 으로 줄어듦
- "소규모 N 에서 CTMC 평균 ≈ ODE" 는 선형계와 초기 단계에서만 정확히 성립한다. 비선형 영역에서는 유한 인구 효과와 조기 소멸 때문에 차이가 나는 것이 정상이며, N 이 커질 때 수렴함으로 검증했다.

마지막 칸 경고: 마지막 칸 I 점유율(I_total >= max(1e-6 N, 10) 인 시점만)이 `simulation.last_bin_warn` (기본 0.05, 1-C 결정) 를 넘으면 `LastBinWarning` 을 낸다. 기본 M = 8 이다.

### 6.1 이동 사건 합치기 (1-C 승인, 수학적으로 같음)

1.3절의 이동 항은 (i, j, c) 쌍마다 율 ω_ij X_{i,c} 인 독립 포아송 사건이다. 이를 다음과 같이 합친다.
- 지역 i 에서 나가는 사건 하나: 율 out_i N_i (out_i = Σ_j ω_ij)
- 도착지 j: 확률 ω_ij / out_i
- 구획 c: 확률 X_{i,c} / N_i

독립 포아송 과정의 중첩·분할에 의해 CTMC 분포가 정확히 같다.
- ODE: drift = ω^T X − out ⊙ X (행렬 곱)
- tau-leap: 구획에서 떠나는 인원을 이항으로 뽑은 뒤 도착지에 조건부 이항으로 배분한다.

검증: 쌍 단위로 쓴 참조 식과 drift 가 일치하고, 쌍 단위 모멘트 방정식과 CTMC 의 평균·분산이 일치한다.
지역 내 사건 수는 K(1 + 6M) 개가 되었다 (합성 17지역, M = 8: 9809 → 833개).

### 6.2 이항 tau-leaping (1-C 승인: 방식 b)

`seir_sim/simulate/tauleap.py` 머리말을 참고한다.
- 단계 시작 인원에서 떠나는 인원을 이항으로 뽑으므로 음수가 생기지 않고 보존이 정확하다.
- 단계 안에서 한 사람은 한 번만 움직이므로 오차는 O(τ) 이다. 선형계에서 τ 를 절반으로 줄이면 오차가 절반이 됨을 확인했다.
- τ 는 Cao-Gillespie-Petzold (2006) 방식이다 (g = 2, ε = 0.03).
- 사건별 마스크(ch_mask, mob_mask)는 하이브리드(2b)에서 쓴다.

### 6.3 SDE (화학 랑주뱅, Euler-Maruyama)

`seir_sim/simulate/sde.py` 머리말을 참고한다.
- 이동 잡음은 (i, j, c) 쌍마다 독립이다.
- 음수 처리 기본값은 `flow_limit` 이다 (docs/DECISIONS.md D-004). 승인안이었던 `increment_clip` 은 dt → 0 에서 편향이 발산함을 확인했다.
- 검증
  - 선형계에서 EM 모멘트 점화식과 일치, O(h) 수렴
  - N = 2e4 에서 CTMC 와 분포 일치
  - N = 1e7 에서 ODE 와 1% 이내
  - 보존 오차 1e-14

### 6.4 하이브리드

`seir_sim/simulate/hybrid.py` 머리말을 참고한다 (승인 분할 방식, leap 를 먼저 적용).
- 검증
  - 소멸 확률 (1/R0)^k 와 일치 (순수 tau-leap 은 실패했던 항목)
  - 전환 기준 (10,5), (100,50), (1000,500) 에서 최종 규모 분포가 CTMC 와 일치 (eps = 0.003)
  - 50~100 전환 구간을 지나는 궤적 분포가 CTMC 와 일치 (매일 평균 z, KS, IQR)
  - 3지역 지역망 전파 분포가 CTMC 와 일치
  - 히스테리시스로 경로당 전환 5회 이하
