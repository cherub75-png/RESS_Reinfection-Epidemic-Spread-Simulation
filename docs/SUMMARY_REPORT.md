# 작업 요약 보고서

재감염 SEIR 전파 시뮬레이터 · 2026-11-09 · 브랜치 `claude/global-reinfection-seir-cubnxv`

## 1. 무엇을 만들었나
- **시뮬레이션 엔진**: 재감염 SEIR 방정식(지시서 1절)을 다섯 가지 방법(ODE, SDE, CTMC, tau-leaping, 하이브리드)으로 푼다. 방정식은 바꾸지 않았다.
- **실제 자료로 추정·예측**: COVID-19 12개국, 인플루엔자 58개 계열(49개국)을 과거 자료로 시간순 검증했다.
- **웹 화면 (로컬)**
  - 오른쪽에 조건을 넣으면 가운데 지도가 감염자 수에 따라 색이 바뀌고, 왼쪽에 시점별 수치가 바뀐다.
  - 인플루엔자 최신 예측 지도와 그래프가 있다.
- **최신 자료**: 시도 경계(통계청 SGIS 2026-10), 인구(WorldPop 2025, World Bank 2025), 기후(ERA5 2025-07 ~ 2026-06)를 쓴다. 설정에서 다른 시기를 고를 수 있다.

## 2. 핵심 결과 (과거 자료 검증, 낮을수록 좋음: 지속 예측 = 1)

| 대상 | 가장 좋은 방법 | 1주 | 4주 | 90% 구간 포함률 |
|---|---|---|---|---|
| 인플루엔자 양성률 (2022-10 ~ 2026-09) | ML + 구간 보정 | 0.86 | 0.78 | 0.89 / 0.88 |
| COVID-19 확진 (2020-07 ~ 2023-01) | ML + 구간 보정 | 0.80 | 0.91 | 0.90 / 0.91 |
| COVID-19 사망 | ML + 구간 보정 | 0.82 | 0.70 | 0.88 / 0.89 |

COVID-19 수치는 구간 보정이 적용된 행(보정 표본이 쌓인 뒤의 기점)에서 잰 값이다 (`docs/reports/12_interval_calibration.md`). 인플루엔자는 `docs/reports/11_influenza_validation.md`.

**잘 된 것**
- 국가 공통 ML이 두 감염병 모두에서 지속 예측보다 낫다.
- ML 구간이 너무 좁던 문제(90% 구간 포함률 0.67~0.84)를 시간순 구간 보정으로 고쳤다. 보정 후 0.88~0.91이다.
- 대한민국 자료를 빼고 학습해도 대한민국 예측 성능이 비슷하다. 특정 국가를 외운 모형이 아니다.

**안 된 것 (그대로 보고)**
- SEIR 모형으로 한 인플루엔자 예측은 지속 예측보다 25~43% 나빴다.
- COVID-19 SEIR은 오미크론 시기에 나빴다.
- 기후 자료(기온·습도)는 1~4주 인플루엔자 예측을 개선하지 않았다.

## 3. 자료 원칙
- 모든 자료에 출처, 받은 날짜, SHA-256, 라이선스를 기록했다 (`docs/DATA_SOURCES.md`).
- 받지 못한 자료는 "미확보"로 두었고, 값을 지어내지 않았다.
- 가정값(이동 규모, 감염병 매개변수 등)은 화면과 문서에서 "가정"으로 표시한다.
- 예측 규칙은 결과를 보기 전에 문서로 고정했다. 바꾼 두 가지는 이유와 함께 변경 기록에 남겼다 (`docs/reports/11_influenza_protocol.md`).
- 자료 문제를 하나 찾아 고쳤다: 이전 시도 경계는 광역시 면적이 2~4배 작았다.

## 4. 남은 한계
- 시도 인구는 모델 추정(WorldPop)이다. 공식 주민등록 인구와 시도별 u(t) 추정은 사용자 결정으로 이번 범위에서 뺐다 (D-027).
- 지역 간 이동 규모는 가정값이다.
- 방정식에 백신·변이·연령 구조가 없다.
- 검증에 쓴 자료가 최종판이라 실시간 성능보다 낙관적일 수 있다.
- COVID-19 자료는 2023-03에 끝난다. 현재 시점 예측은 인플루엔자만 가능하다.
- 공개 배포는 하지 않았다 (로컬 실행판).
