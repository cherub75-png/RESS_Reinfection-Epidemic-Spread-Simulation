## 2. 현재 사용하는 방정식

방정식은 작업 지시서 1절과 같다. 바뀐 곳은 없다. 아래는 구현에서 쓰는 형태와 값이다.

### 2.1 첨자와 구획
- 지역 i = 1…K, 감염 횟수 n = 1…M (M = 8; 마지막 칸은 "M회 이상")
- 구획: S_i, E_{n,i}, I_{n,i}, R^P_{n,i} (보호), R^W_{n,i} (면역 소실), D_i
- m(n) = min(n+1, M)
- N_i(t) = S_i + Σ_n (E + I + R^P + R^W)_{n,i}

### 2.2 감염 횟수별 함수
- 감수성 (n번째 감염): P(n) = P_min + (P_1 − P_min) e^{−α(n−1)}
- 전파력: T(n) = T_1 n^{−β}
- 회복 후 경과 시간 τ 의 감수성: P(n,τ) = P(n) + [P_1 − P(n)](1 − e^{−λτ})
  - R^P_n 은 P(n+1), R^W_n 은 P_1 을 쓰고, R^P → R^W 를 율 λ 로 옮긴다.
  - 재감염이 없을 때 기댓값이 P(n+1, τ) 와 정확히 같다.
  - 재감염이 있으면 차이는 Λ 의 2차다 (Jensen 부등식).
- 치사율: f(n) = f_1 φ(n), φ(n) = n^{−0.5}
- 마지막 칸 R^P_M 은 P(M+1) 을 쓴다. 이는 "M 이후 함수 값을 고정한 무한 칸 모형"과 정확히 같다.

### 2.3 접촉과 감염력
- 지역 접촉률: c_i(t) = c_0 · h(ρ_i) · (1 − u_i(t))
  - h(ρ) = (ρ/ρ_ref)^η, η = 0.2, ρ_ref = 인구가중 평균 밀도
  - u_i(t): 방역 개입 강도 (기본 0)
- 환경 보정: g_i(t) = 1 (기본, 효과 없음). 후보 형태는 g = exp[a_T (T − T_ref) + a_H (H − H_ref)] 이고, 계수는 2단계에서 추정한다.
- 감염력: Λ_i(t) = g_i(t) c_i(t) Σ_j C_ij [Σ_k T(k) I_{k,j}] / N_j
- 장거리 이동: 𝓜_i[X] = Σ_j (ω_ji X_j − ω_ij X_i)  (D 제외)

### 2.4 평균장 ODE (모든 i, n = 1…M)
```
dS_i/dt      = −P_1 Λ_i S_i + 𝓜_i[S]
dE_{n,i}/dt  = Λ_i [ 1{n=1} P_1 S_i + Σ_{l: m(l)=n} ( P(l+1) R^P_{l,i} + P_1 R^W_{l,i} ) ] − σ E_{n,i} + 𝓜_i[E_n]
dI_{n,i}/dt  = σ E_{n,i} − γ I_{n,i} + 𝓜_i[I_n]
dR^P_{n,i}/dt = (1 − f(n)) γ I_{n,i} − [ λ + P(n+1) Λ_i ] R^P_{n,i} + 𝓜_i[R^P_n]
dR^W_{n,i}/dt = λ R^P_{n,i} − P_1 Λ_i R^W_{n,i} + 𝓜_i[R^W_n]
dD_i/dt      = γ Σ_n f(n) I_{n,i}
```

### 2.5 공통 사건 목록 (모든 방법이 공유)
각 항은 "한 사람을 구획 src 에서 dst 로 옮기는" 사건이다.

  a_j(X,t) = [k_j + s_j Λ_{r_j}(X,t)] · X[src_j],   ν_j = e_dst − e_src

| 사건 | 이동 | 율 |
|---|---|---|
| 첫 감염 | S → E_1 | P_1 Λ S |
| 재감염 (보호) | R^P_l → E_{m(l)} | P(l+1) Λ R^P_l |
| 재감염 (소실) | R^W_l → E_{m(l)} | P_1 Λ R^W_l |
| 발병 | E_n → I_n | σ E_n |
| 회복 | I_n → R^P_n | (1 − f(n)) γ I_n |
| 사망 | I_n → D | f(n) γ I_n |
| 면역 소실 | R^P_n → R^W_n | λ R^P_n |
| 이동 | X_i → X_j | 합쳐서 out_i N_i (도착지 ∝ ω_ij, 구획 ∝ X_ic); 분포가 원래와 정확히 같음 |

### 2.6 확률 모형
- **CTMC** (정확): 마스터 방정식 ∂p/∂t = Σ_j [a_j(x − ν_j) p(x − ν_j) − a_j(x) p(x)]
  - Gillespie: τ = −ln u_1 / a_0, 사건 j 를 확률 a_j / a_0 로 선택
- **SDE** (화학 랑주뱅): dX = Σ ν_j a_j dt + Σ ν_j √a_j dW_j, Euler–Maruyama, 흐름 제한 음수 처리
- **이항 tau-leaping**: 구획을 떠나는 인원 ~ Binomial(x_s, 1 − e^{−K_s τ}), 사건별로 조건부 이항 배분, τ 는 Cao–Gillespie–Petzold 방식 (ε = 0.01)
- **하이브리드**
  - 지역 E+I < 50 → 감염 관련 사건은 CTMC
  - 지역 E+I ≥ 100 → tau-leap (히스테리시스)
  - S·R 만 관련된 사건은 항상 tau-leap

### 2.7 분석식
- 초기 증가율 (단일 지역): r = [−(σ+γ) + √((σ−γ)² + 4σκ)] / 2,  κ = g c P_1 T_1
- 기본 재생산수 (단일 지역): R_0 = κ / γ
- 지역망: R = ρ(F V^{−1}). 정확한 축소식:
  - R = ρ( diag(a_eff · g c) · C · diag(1/N) · σ (γI + L)^{−1} (σI + L)^{−1} )
  - L = diag(Σ_j ω_ij) − ω^T,  a_eff,i = Σ_n T(n) A_{n,i}
- c_0 보정: R 이 c_0 에 정확히 비례하므로 c_0 = R_0,목표 / R(c_0 = 1)

### 2.8 출력 통계 (1.6절)
- I_total(t) = Σ_i Σ_n I_{n,i}(t)
- 평균, 분산 Var = (1/(R−1)) Σ_r (I^{(r)} − Ī)², 5–95% 구간
- 대유행 확률 = P(max_t I_total ≥ 1000)

### 2.9 자료로 만드는 입력 (데이터 계층)
- 통근 접촉 C (radiation 모형): w_ij ∝ m_i m_j / [(m_i + s_ij)(m_i + m_j + s_ij)],  C_ij = a_c a_s w_ij,  C_ii = 1 − a_c a_s
- 항공 이동 ω: F_ij = F_ji = (하루 이동 횟수) × (R_ij + R_ji) / Σ(R + R^T),  ω_ij = F_ij / N_i  (R = 노선 수, 균형 보장)
- 상대습도 (Tetens): e_s(T) = 0.6108 exp(17.27 T / (T + 237.3)) kPa, RH = 100 e / e_s

## 3. 다음 작업(2단계: 실제 자료 보정)에 필요한 것

### 3.2 사용자가 주실 자료·정보
- **실제 감염 자료**
  - 질병명 (예: COVID-19)
  - 지역 (예: 대한민국 시도 / 전 세계 국가)
  - 기간
  - 파일 또는 출처 (예: 일별 확진·사망·입원·검사 수)
- **예측 목표**: 확진, 입원, 사망 중 무엇을 맞출지
- **정확도 지표 선호**: 예측 구간 적중률, CRPS, MAE 등
- **예방접종·방역 정책 자료** (있으면): u_i(t) 와 면역 상태 반영용

### 3.3 환경 설정 (자료 서버 허용)
환경 설정 → Network access → Allowed domains 에 다음 도메인을 추가하거나, 파일을 직접 제공한다.
- `data.worldpop.org`: 인구 격자 (대한민국 시도 인구)
- `geodata.ucdavis.edu`: WorldClim 기후
- 과거 날씨 재현이 필요하면 ERA5 (Copernicus CDS, 계정과 API 키 필요)

### 3.4 2단계 작업 계획 (승인 후 진행)
1. 실제 자료 정리와 품질 보고: 결측, 보고 지연, 과소보고
2. 관측 모형 설계: 보고율, 보고 지연 분포
3. 학습 대상 정하기
   - 상수: σ, γ, c_0, α, β, λ, f_1 등
   - 함수: h, g, φ, u_i(t)
   - 식별 가능성 분석을 먼저 한다 (예: c_0, P_1, T_1 은 곱으로만 식별된다)
4. 추정 방법: 입자 필터 또는 ABC, 필요하면 신경망 대리모형
5. 시간순 학습/검증 분리 (미래 누설 금지)
6. 방법 비교: ODE·SDE·CTMC·하이브리드를 같은 지표로 비교
7. 최적 모형과 매개변수 사후분포 저장

## 4. 다음 작업 권장 노력 수준
- **2단계 전체: 엑스트라(xhigh)**
  - 관측 모형, 우도, 입자 필터 설계, 시간 분리 검증, 식별 가능성 분석은 실수하면 결과 해석이 통째로 틀어진다.
  - 최대(max)는 사용량 대비 이득이 작다. 막히는 문제가 생길 때만 올리는 것을 권한다.
- 자료 정리·변환만 하는 짧은 하위 작업은 **높음(high)** 으로도 충분하다.
